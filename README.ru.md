# tele

[English](README.md) · [Русский](README.ru.md)

Форк Telegram Desktop: очередь патчей поверх стабильных релизов [tdesktop](https://github.com/telegramdesktop/tdesktop), которую GitHub Actions собирает в этом репозитории.

За основу взят [nitreojs/tele](https://github.com/nitreojs/tele). [@acaff](https://t.me/acaff) добавил русский перевод меню и подменю tele, названий и описаний настроек. Для перевода выберите русский язык в настройках Telegram. Обновления используют ключ подписи и релизы этого форка; адрес сервера tele по умолчанию пустой.

## Скачать

Последнюю сборку скачивайте из [релизов](https://github.com/AppleVibe/tele-ru/releases/latest). Сборки не затрагивают установленный Telegram и его данные.

| Платформа | Файл | Установка |
| --- | --- | --- |
| Windows x64 | `tele-<version>-win64.zip` | Распакуйте в любую папку и запустите `tele.exe`. Данные хранятся рядом с exe. Приложение добавляет себя в меню «Пуск». |
| Linux x64 | `tele-<version>-linux64.zip` | Распакуйте в доступную для записи папку, например `~/.local/opt/tele`, и запустите `./tele`. Данные хранятся в `~/.local/share/tele`. Приложение добавляет себя в меню приложений. |
| macOS (Apple Silicon и Intel) | `tele-<version>-macos.dmg` | Перетащите tele в «Программы» и один раз выполните команду ниже: сборка не нотаризована. Данные хранятся в `~/Library/Application Support/tele`. |

```
xattr -dr com.apple.quarantine /Applications/tele.app
```

tele проверяет эти релизы каждые 3 часа, скачивает обновления в фоне и предлагает перезапуск. Фид подписан, поэтому приложение не установит сборку с неподходящей подписью. Автообновления отключаются в «Настройки → tele → Обновления».

Для каждого ZIP и DMG сборка создаёт [аттестацию происхождения](https://github.com/AppleVibe/tele-ru/attestations). Проверить скачанный файл можно через [GitHub CLI](https://cli.github.com):

```
gh attestation verify tele-<version>-win64.zip --repo AppleVibe/tele-ru
```

## Основные возможности

Все дополнения tele находятся в «Настройки → tele», под строкой выбора языка.

- [Студия подарков](docs/features.md#gift-studio): создавайте коллекционные подарки из настоящих частей и экспортируйте в PNG, MP4, GIF или стикеры TGS.
- [Режим призрака](docs/features.md#privacy): скрывайте прочтение, набор текста, онлайн-статус и просмотры историй во всех или выбранных чатах.
- [Центр уведомлений](docs/features.md#notifications): уведомления tele, обновления, отчёты о сбоях и сообщения сервера в одном списке.
- [Консоль MTProto](docs/features.md#debug): вызывайте методы API своей сессией, с автодополнением и подсказками схемы.
- [Скрипты](docs/scripting.md): плагины JavaScript и TypeScript с доступом к Telegram API, веб-платформе и окнам tele. Каждое разрешение требует вашего согласия. Готовые скрипты есть в [каталоге](https://gettele.app/scripting/catalog).
- [Дизайны карты Money](docs/features.md#chats): оформляйте карту своим коллекционным подарком и размещайте подарки на ней как наклейки.
- [Сохранение удалённых сообщений](docs/features.md#messages): сообщения, удалённые другими, остаются в чате, при желании и после перезапуска.
- [Локальные папки и закрепления](docs/features.md#interface): больше папок, чатов в папке и закреплённых чатов, чем разрешает Telegram. Дополнительные данные остаются на этом устройстве.
- [Медиа над полем ввода](docs/features.md#sending): прикрепляйте медиа над полем, каждому задавайте подпись и сохраняйте всё как черновик.
- [Снимки сообщений](docs/features.md#menus): сохраняйте сообщения как картинку с фоном чата или без него.
- [Цитаты rich-сообщений](docs/features.md#messages): цитируйте часть форматированного сообщения и отвечайте в rich-редакторе.
- [Подписи к стикерам](docs/features.md#chats): отправляйте стикеры с текстом и читайте подписи под ними.
- [Режим стримера](docs/features.md#privacy): скрывайте tele от захвата экрана, имена и текст в уведомлениях, а также номер телефона.
- [Автообновление](docs/features.md#updates): подписанные обновления из релизов этого репозитория для Windows, Linux и macOS.

## Благодарности

- [tdesktop](https://github.com/telegramdesktop/tdesktop), из которого собирается каждый выпуск tele.

Его идеи легли в основу скрытия хвостиков пузырей, классических отступов, отключения обводки больших эмодзи, выбора более 100 сообщений, отображения онлайн-участников больших групп, даты загрузки медиа, копирования ID владельца набора стикеров, улучшенного качества голоса и сохранения начала записи, меньшего сжатия фото, тонкой кисти, меньшего минимального окна, расширенного экспорта чата и последовательных упоминаний нескольких людей.
- [freshGram](https://github.com/Snowy-Fluffy/freshGram) от Snowy-Fluffy, объединяющий [AyuGram Desktop](https://github.com/AyuGram/AyuGramDesktop) и materialgram. Из него перенесён прототип секретных чатов. Его идеи использованы для фильтра по типу сообщений, сохранения удалённых чатов и тем, просмотра скрытого времени последнего посещения и отключения баннеров дней рождения.
- [SPOwnerBot](https://github.com/arynyklas/SPOwnerBot) от arynyklas и [его форк](https://github.com/madrik1337/SPOwnerBot) от madrik1337: способ определения владельца по ID набора стикеров, включая владельцев с ID больше 8 миллиардов.

- [docs/conventions.md](docs/conventions.md): стиль кода, коммитов и патчей, правила приватности.
- [docs/releasing.md](docs/releasing.md): сборка, подпись и публикация релизов.
- [AGENTS.md](AGENTS.md): правила для ИИ-агентов разработки.
